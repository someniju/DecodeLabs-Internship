# 📂 Data Folder

## 📌 Overview

This folder contains the datasets used in my Data Cleaning Project as part of my Data Analytics internship with DecodeLabs.

The folder includes cleaned datasets in Excel and CSV formats.

## 📁 Files Included

| File Name | Description |
|---|---|
| `Cleaned_Dataset_Python.xlsx` | Cleaned dataset generated using Python/Pandas |
| `Cleaned_Dataset_Python_Excel.xlsx` | Cleaned dataset prepared using Excel |
| `Cleaned_Dataset_Python.csv` | Cleaned dataset exported in CSV format |

## 🎯 Purpose

The purpose of this folder is to maintain the cleaned datasets separately from the original raw dataset.

These files can be used for further data analysis, exploratory data analysis (EDA), data visualization, and reporting.

## 🛠️ Tools Used

- Microsoft Excel
- Python
- Pandas
- CSV
