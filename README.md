# 📊 Data Cleaning Project

## 📌 Project Overview

This project focuses on cleaning, validating, and preparing a raw dataset for further data analysis.

As part of my Data Analytics internship with **DecodeLabs**, I worked with both **Excel and Python (Pandas)** to identify data-quality issues and create a cleaner, analysis-ready dataset.

## 🛠️ Tools Used

- Microsoft Excel
- Python
- Pandas

## 🔍 Data Cleaning & Validation Steps

The project involved the following steps:

1. Loaded and explored the dataset.
2. Checked the number of rows and columns.
3. Reviewed column names and data types.
4. Identified missing values.
5. Calculated missing-value percentages.
6. Investigated records with missing `CouponCode`.
7. Handled missing `CouponCode` values.
8. Checked for duplicate records.
9. Checked for duplicate `OrderID` values.
10. Validated categorical values such as Payment Method, Order Status, Product, and Referral Source.
11. Checked the date range.
12. Performed numerical data analysis on Quantity, UnitPrice, ItemsInCart, and TotalPrice.
13. Identified potential outliers using the IQR method.
14. Verified the `TotalPrice` calculation using Quantity × UnitPrice.
15. Checked for negative values.
16. Reviewed text consistency across categorical fields.
17. Exported the cleaned data into Excel and CSV formats.

## 🔄 Project Workflow

**Raw Data → Data Cleaning → Data Validation → Clean Dataset → Ready for Analysis**

## 💡 Key Learnings

- Data cleaning is an important foundation for reliable analysis.
- Missing values and duplicates need to be investigated before analysis.
- Data validation helps identify inconsistencies and incorrect values.
- The IQR method can be used to identify potential outliers.
- Excel and Python/Pandas can complement each other in practical data-cleaning workflows.

## 🎯 Outcome

The raw dataset was reviewed, cleaned, validated, and exported into **Excel and CSV formats**, making it more suitable for further analysis.
